# SillyTavern 聊天记录管理器 (Chat Cleaner & Manager)

**简体中文** | [English README](./README.md)

一款专为 **SillyTavern (酒馆)** 打造的可视化、高安全性的全局聊天记录管理与废档清理扩展。

随着角色卡数量增加，酒馆中往往会堆积成百上千个"点开看了一眼就关掉（仅 1 条开场白）"的冗余 `.jsonl` 聊天文件。本插件支持跨角色增量秒扫、多维度筛选、按楼层折叠预览、单文件导出，并内置 **原子级回收站** 与 **多层级防误触保护**。

## ✨ 核心特性

- **⚡ 增量签名缓存（秒级扫描）**：自动比对角色卡最后聊天签名，未发生变动的角色卡直接读取本地 IndexedDB 缓存（零网络请求），自动跳过无记录空卡，支持 2~16 线程并发扫描及随时暂停/继续/终止。
- **🛡️ 多层级数据安全防线**：
  - **当前打开对话强制豁免**：自动识别酒馆前台正在进行的活跃对话（标为 `当前打开`），禁止直接勾选，防止删掉当前对话导致酒馆状态报错或自动复写。
  - **异常大体积少消息防误触（防误删崩溃坏档）**：当文件显示 ≤ 2 条消息但体积达到设定阈值（默认 `≥ 15 KB`，可在设置中自由调整或关闭）时，自动标记为 `大体积少消息(慎删)`。「全选普通项」与「快捷预设」会自动跳过它们，手动勾选清理时则会弹出醒目的红色高危确认框。
  - **分支、书签与主干保护**：自动构建父子分支反向索引，分支节点及含有子分支的主干聊天默认跳过全选，防止误删主干导致剧情树断链。
  - **删除前实时状态核对**：删除前拉取文件真实内容，拦截空数组异常，若实际消息条数与缓存不符则自动跳过并同步最新状态。
  - **断网保护的原子级回收站**：元数据与聊天正文分离存储，且必须在同一 IndexedDB 事务中备份成功后才允许发起物理删除；一旦浏览器存储空间不足导致备份失败，立即中止删除原文件。若删除请求途中网络中断，强制保留回收站备份绝不回滚。
  - **可自定义保留时长**：回收站保留时间可自由设置为 5 分钟 ~ 7 天，或设置为永不自动清理。
- **👁️ 按楼层折叠轻量预览 & 本地导出**：不执行酒馆繁重的正则与前端 HTML 渲染，秒开不卡顿。长对话自动折叠中间楼层，打开即**自动定位到最后一楼**，支持一键下载 `.jsonl` 文件到本地。
- **🌐 内置中/英双语无缝切换**：默认简体中文，在首次免责弹窗、顶栏 `🌐 EN/中文` 按钮或设置面板中均可一键切换中英文。
- **👤 多用户数据隔离**：自动按 SillyTavern 用户标识隔离 IndexedDB 与本地设置，同一浏览器切换多个账号时彼此不会看到对方的回收站数据。

## 📦 安装方法

打开 SillyTavern 顶栏的 **扩展 (Extensions)** 页面 → 点击 **安装扩展 (Install Extension)**，输入以下仓库地址：

`https://github.com/waignin/SillyTavern-ChatCleaner`

> **手动安装路径提醒**：若使用压缩包或 `git clone` 手动安装，请放置在 `SillyTavern/public/scripts/extensions/third-party/SillyTavern-ChatCleaner/` 目录下。建议使用 **SillyTavern 1.17.0 及以上版本**。
>
> **安装指定版本**：可在地址末尾追加标签，例如 `https://github.com/waignin/SillyTavern-ChatCleaner#v1.1.0`。

## 🚀 使用指南

1. 点击酒馆聊天界面左下角或顶栏的 **魔法棒图标 (🪄 扩展菜单)**，点击 **「聊天记录管理」**。
2. 在默认展开的筛选器中，可按 **消息数范围**（默认 `0 ~ 1`）、**文件体积 (KB)**、**未对话天数** 筛选，或点击 **「≤ 1 条消息 (废档)」** 快捷预设按钮一键勾选普通废档。
3. 点击任意行的 **「预览」** 可按楼层查看对话内容，点击 **「导出」** 可将 `.jsonl` 保存至电脑/手机本地。
4. 点击右下角 **「清理选中项」** 完成清理。被删文件可在 **「回收站」** 标签页中随时恢复、加锁永久保留或导出（默认保留 60 分钟，可在设置中调整）。

## ⚠️ 安全须知与风险

- **回收站依赖浏览器存储**：删除的聊天记录保存在当前浏览器的 IndexedDB 中。**期间请勿清除浏览器站点数据**，也避免使用无痕模式，否则回收站内的备份将丢失。
- **当前对话受保护**：正在前台打开的活跃聊天会被**自动豁免**，无法被勾选删除。如需清理请先切换到其他聊天。
- **物理删除不可逆**：如果关闭"删除前自动备份至回收站"，或在回收站中执行"销毁"，文件将从硬盘物理移除，本插件无法找回。
- **外部手动改文件风险**：若在操作系统文件夹中直接修改或新增 `chats/` 下的文件，请点击一次 **「全量重扫」** 同步插件缓存。
- **已删除角色卡的孤儿聊天**：本插件仅扫描当前角色卡对应的聊天记录。已删除角色残留的 `chats/` 文件夹，请使用 SillyTavern 官方内置的 **Clean-Up Menu**（设置 → 数据清理）处理。
